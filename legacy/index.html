Features

Built around how developers actually work

One glance at the panel tells you where you stand before you start the next refactor.

01

Usage bars with reset countdowns

Session, weekly, and monthly limits as percentage bars. Exact time until each window resets.

02

Cost tracking

Today's spend, 30-day total, and token counts. Know your burn rate without opening a dashboard.

03

Clickable provider switcher

Five providers in a tile row inside the popup. Click any tile to drill into its detail view.

04

Auto-refresh loop

Configurable from 1 minute to 5m+. Stale data markers when a fetch is overdue. Each provider isolated.

05

Adjustable UI

Compact or comfortable density. Popup opacity 35–100%. Adapts to any GNOME desktop theme.

06

Per-provider error isolation

A failing provider shows an error state without blocking the rest. 5-second timeout per provider.

Privacy

Local first.
No surprises.

Most providers need nothing from you. CodexBar reads the same local files your CLI tools already write. Every file path and API endpoint the extension can touch is listed in Settings under the Privacy panel.

  • ~/.claude/ Session logs and usage data
  • ~/.codex/ Codex state JSON
  • ~/.config/gcloud/ Gemini via gcloud
  • openrouter.ai/api/v1/auth/key Balance check, API key only if configured

Install

Up in 30 seconds

Step 01

Clone and install

One command. Compiles schemas and enables the extension via the GNOME extensions CLI.

$ git clone github.com/local/codex-bar-gnome
$ ./scripts/install.sh

Step 02

Reload GNOME Shell

X11: Alt+F2 then r. Wayland: log out and back in, or use the nested dev session.

# Wayland: watch + nested session
$ ./scripts/install.sh -w -n

Step 03

Configure providers

Enable providers and enter optional API keys in the extension preferences panel.

$ gnome-extensions prefs codex-bar-gnome@local

Requirements

GNOME Shell 46 · glib-compile-schemas · gnome-extensions · Node.js 20+ (tests only)

sudo apt install gnome-shell-extension-prefs glib2.0-bin
